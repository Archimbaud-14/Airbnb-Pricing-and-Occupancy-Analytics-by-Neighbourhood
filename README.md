# Airbnb Pricing and Occupancy Analytics by Neighbourhood

## 📌 Project Overview
This project analyzes Airbnb listing and calendar data to benchmark pricing across neighbourhoods, measure seasonal price variation, and calculate occupancy rates to identify the highest-value areas for hosts and property investors.

## 🎯 Learning Objectives
1. Merge listing and calendar data to compute occupancy metrics.
2. Benchmark pricing across geographic segments using median statistics.
3. Identify seasonal pricing patterns from daily calendar data.

## 📂 Project Structure
- `Airbnb_Pricing_Occupancy_Analysis.ipynb`: Main Jupyter notebook containing the full data analysis pipeline, visualizations, and code.
- `note.md`: Detailed methodology, key findings, and actionable insights.
- `listings.csv` & `calendar.csv`: Raw datasets used for the analysis.
- `*.png`: Exported visualization charts.

## ⚙️ Technical Stack
- **Python 3.13**
- **Libraries**: `pandas`, `matplotlib`, `seaborn`, `numpy`

## 🚀 How to Run
1. Ensure all dependencies are installed (`pip install pandas matplotlib seaborn numpy`).
2. Open the `Airbnb_Pricing_Occupancy_Analysis.ipynb` notebook in Jupyter.
3. Run all cells to reproduce the data cleaning, analysis, and visualizations.
